Two focused tools, zero clutter

Purpose-built utilities that do one job well and stay out of your way.

File Difference Checker

Load two versions of a file and review every difference side by side. Choose which side to keep for each change, then export a clean merged result.

  • Line-by-line diff with clear highlighting
  • Per-change "keep original / keep modified" controls
  • One-click merged output export

Kubernetes YAML Optimizer

Paste or load a manifest and get a clean, apply-ready result. CoreTools validates the schema and strips redundant, server-managed noise to industry best practices.

  • Removes server-managed fields & status blocks
  • Strips tooling annotations, nulls & empty values
  • Transparent changelog of every removal

Privacy by design

Your data never leaves your device

CoreTools is built to be trustworthy, not just convenient. There is no network code, no telemetry, and no hidden background activity. Everything you do stays on your machine.

  • Fully offline. No external API calls, no update pings, no analytics — enforced by a strict Content Security Policy.
  • No data transfer. Nothing you load or generate is ever uploaded, shared, or synced.
  • No storage. All processing happens in memory. No caches, logs, or temp files — files are written only when you explicitly save them.
  • Safe by construction. Sandboxed, data-only YAML parsing with strict validation. No code execution, no eval.
