Features

Three focused tools, zero clutter

Diff-Checker

Compare two versions of any file side by side, decide which side to keep for every change, and export a clean merged result.

  • Line-by-line diff with clear highlighting
  • Per-change keep / discard controls
  • One-click merged output export

YML-Validator

Paste a manifest and get a clean, apply-ready result. Validates the schema and strips server-managed noise to best practices.

  • Removes server-managed fields & status
  • Strips tooling annotations & empty values
  • Transparent changelog of every removal

Grammar-Polisher

Rewrite any sentence in the style you need, with instant output and one-click copy — entirely offline, inside the app.

  • Professional — formal, polished business English
  • Gen Z — casual, trendy phrasing
  • Complete — balanced, clear, fully fleshed out

Privacy by design

Your data never leaves your device

CoreTools is fully offline: no external API calls, no telemetry, no analytics, no hidden background activity. All processing is in-memory — nothing is stored, cached, or transferred. Even this website ships zero trackers and makes no third-party requests.

  • Fully offline. No network code in the app — enforced by a strict Content Security Policy.
  • No data transfer. Nothing you load, type, or generate is ever uploaded, shared, or synced.
  • No storage. All processing happens in memory. Files are written only when you explicitly save them.
  • Safe by construction. Sandboxed, data-only parsing with strict validation. No code execution, no eval.

Verify your download (SHA-256 checksums)
  • Checksums are published with every release, next to the installers they describe.

Verify with certutil -hashfile <file> SHA256 (Windows), shasum -a 256 <file> (macOS), or sha256sum <file> (Linux) and compare against the release's SHA256SUMS.txt.

Windows may warn about this download. CoreTools is not yet code-signed, so SmartScreen can flag new releases as "unverified". Only proceed with an installer whose SHA-256 checksum you have verified against the release's SHA256SUMS.txt; if you can't verify it, or would rather skip the warning entirely, use the in-browser app below — same tools, no installer.

Don't want to install (or fight the warning)? Use CoreTools in your browser — same tools, nothing to download.
